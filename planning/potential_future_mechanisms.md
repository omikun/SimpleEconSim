# Potential future mechanisms

This is the review guide for proposals collected by the on-demand AI stat
explainer. Generated records live in `potential_future_mechanisms/*.json`.
No proposals have been approved by creating this guide.

Each proposal is a possible future design, **not an implemented game action**.
Generation happens only as part of a player-requested explanation when a
specific missing capability is identified. A temporarily unaffordable or locked
action is not, by itself, a missing mechanic.

Records contain the unmet need, the gap in existing capabilities, proposed
behavior, tradeoffs, acceptance criteria, supporting evidence/history IDs, and
triggering run/turn/stat provenance. Equivalent proposals merge provenance;
cache hits do not create duplicates. New proposals start with status `proposed`.
Reviewers may change status to `under_review`, `accepted`, `rejected`, or
`implemented` and add review notes. Subsequent logging preserves those fields.

Review a proposal against the current game code and scenario before adopting
it. AI catalog coverage and historical analogies do not establish that the
design is absent, feasible, balanced, or historically effective. Logging does
not authorize or schedule implementation.
