Milestone E: Province model — shared bank/gov/charity + audit dedupe

=== WHAT ===
- province.py: Province owns ONE shared InstitutionBundle (bank/gov/charity)
  and add_tile() re-points member tiles at it; Province.step runs the
  once-per-province institutional flow (charity collect --> per-tile economy
  via Region.step_economy --> deposit interest --> charity distribute -->
  gov seal_income).  partition_contiguous() splits each nation's contiguous
  hex cluster into 1-3 contiguous sub-provinces (by size: <3=1, <=4=2, else 3).
- region.py: Region.__init__ accepts institutions= (shared bundle) and
  seat_gov= (only the FIRST member tile appends the shared government agent
  to its agents list, so per-tile audit lists can't double-count the gov);
  step() delegates to step_economy() which SKIPS the province-wide
  institutionals (legacy tiles keep the original byte-identical flow);
  _collect_tax runs only on the gov-seated tile of a province.
- forex.py: audit_currency_total id-dedupes shared banks/charities (and
  reserves per currency) so a shared province bundle is counted once, not
  once per member tile.  Legacy 1:1 ids are unique -> byte-identical.
- nation.py: Nation.provinces list (aggregation seam).
- sim_world.py: starting clusters are partitioned into Provinces; member
  tiles are CONSTRUCTED with the shared bundle (no per-tile bank capital is
  ever abandoned) + seat_gov on the first tile; the main loop drives
  Province.step for all provinces and r.step() only for legacy/wild tiles.

=== NOTE (follow-up) ===
claims.py still uses the legacy per-tile institutions deliberately: fresh
claims start with a 0-capital bank + 0-cash gov (founding-charter rule);
wrapping them in a standard Province -- which seeds capital=2000 + gov=200 --
would MINT money.  Province-ifying claims (a Province that adopts existing
0-capital institutions without seeding) is the next step.
